# Authoring Portfolio

A personal portfolio showcasing projects from my BSc in Software Development built for the Authoring for Digital Media module.

- **Live site:** [meghankeightley.com](https://meghankeightley.com/)
- **GitHub Pages (static version):** [meghank1066.github.io/authoring-portfolio](https://meghank1066.github.io/authoring-portfolio/)

The site uses a ladybug and garden theme, inspired by a game analysis paper I wrote on the arcade game *Lady Bug*. The idea is that I'm a gardener finding and fixing bugs, the same way a developer does in code.

## Pages

- **Home**: introduction and project cards linking to each case study
- **About**: a scrapbook-style page with a bit more about me
- **Ladybug Sightings**: a visitor log where visitors can leave their mark on the garden
- **Project case studies**: Velora, SPOREX, NexSpace and Nintendo

## Features

- Side navigation in place of a standard top bar, meant to feel like a garden path
- Hand-drawn animations made in Procreate
- A trail-style scroll indicator showing where you are on each page
- A "Patch Notes" section that works as a small log of updates in my professional life
- Responsive layouts using Flexbox, Grid and media queries
- HTML and CSS validated with the W3C validators

## Built with

- HTML, CSS and JavaScript
- Node.js and Express for the visitor log backend
- MongoDB Atlas for storing visitor entries
- Render for hosting the full site

GitHub Pages only serves static files so the visitor log only works on the hosted version at meghankeightley.com.

## Design

- Typeface: Gelica (Adobe Fonts)
- Colours: pale pink `#F7D6DD` and deep red `#B5222F`
- Each page has its own stylesheet, with a shared `style.css` for the navigation and other global elements
